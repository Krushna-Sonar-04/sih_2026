# DRISHTI Phase 1 — Light Institutional Rebuild

## Goal
Transform the existing prototype into a presentation-ready, frontend-only social-media narrative intelligence workspace with a distinctive light institutional identity and one shared analytical clock.

## Build
- Replace the dark cyber-style palette with warm-neutral light surfaces, deep navy branding, refined blue accents, restrained signal colors, thin borders, and readable enterprise typography.
- Redesign the application shell and original DRISHTI wordmark; preserve the collapsible sidebar while improving active states, header context, analyst identity, and laptop responsiveness.
- Refine the Dashboard around the Active Watch, exact metrics, intelligence-event rows, and a structured Recent Watches table with working primary actions.
- Make Watches, Alerts, History, System Health, and Settings complete, polished Phase 1 views using deterministic demo content rather than placeholders.
- Rebuild the Narrative Time-Machine as the signature experience: one analytical timeline, synchronized sentiment, narrative ranking, influence graph, evidence, demographics, and a collapsible “At this moment” panel.
- Keep all content honest: clearly label simulated data and avoid claims of live platform connectivity.

## Technical details
- Use existing React, TypeScript, Tailwind CSS, shadcn primitives, Recharts, and React Flow.
- Keep demo datasets separate from visual sections where practical and preserve semantic design tokens.
- Add no database, authentication, APIs, ingestion, or production AI services.
- Verify every route, primary interaction, and visual layout at 1366×768, 1440×900, and 1920×1080.
