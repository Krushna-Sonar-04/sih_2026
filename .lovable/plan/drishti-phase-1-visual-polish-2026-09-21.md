# DRISHTI Phase 1 Visual Polish

## Goal
Refine the existing Phase 1 interface into a spacious, light, government-facing analytical product without changing routes, demo data, interactions, or product scope.

## Visual changes
- Replace the dominant left sidebar with a spacious top-navigation shell for Dashboard, Watches, Narrative Time-Machine, Alerts, and History.
- Keep System Health, Settings, and analyst details inside a compact utility menu so analytical content becomes the primary focus.
- Widen the centered workspace, strengthen typography, and increase major-section spacing across all pages.
- Recompose the Dashboard around a distinctive tinted Active Watch entry point, a unified metric band, editorial attention rows, and a refined institutional table.
- Recompose the Narrative Time-Machine around a prominent timeline and shared-clock spine, then vary the visual structure of sentiment, narratives, network, evidence, and demographics instead of repeating identical cards.
- Preserve the current light palette while refining navy, institutional blue, indigo, neutral surfaces, borders, and status colors.

## Validation
- Verify all existing routes and key interactions still work.
- Visually inspect Dashboard and Narrative Time-Machine at 1366×768, 1440×900, and 1920×1080.
- Check for overflow, clipped labels, weak hierarchy, and browser errors.

## Scope guard
Frontend visual refinement only. No backend, new product functionality, or Phase 2 work.
